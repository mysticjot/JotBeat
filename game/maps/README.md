# Maps

- `build_map.py` — **source of truth**: the dungeon layout (floor rects, wall shell, gameplay
  anchors). Run `python game/maps/build_map.py` from the repo root to regenerate both outputs.
- `dungeon.ldtk` — the LDtk project (1.5.3 schema), generated by `build_map.py`; open it in the
  [LDtk](https://ldtk.io) app to view/edit visually. Hand edits are overwritten by the next
  generator run — change the generator, not the JSON.
- `../assets/maps/dungeon.json` — the Tiled-format export that Vite serves and Phaser loads via
  `this.load.tilemapTiledJSON`. Generated by the same script; the two files cannot drift.

Gameplay anchors (spawn / key / door / exit tiles) live at the top of `build_map.py`. They are
duplicated as pixels in `game/src/scenes/Game.ts` (`LAYOUT`) and as waypoints in the Playwright
specs — move a tile in the generator and update both.

The tileset image (`../assets/tilemaps/dungeon.png`) comes from
`game/tools/build_kenney_assets.py` (Kenney Tiny Dungeon, CC0). gid contract: 1 = floor,
2 = wall, 3 = void (solid), 4-6 = floor variants; collision is `setCollisionBetween(2, 3)`.
